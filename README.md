# میز پیگیری و مدیریت تسک‌ها (sovapp)

سامانه جامع و یکپارچه مدیریت، پیگیری و گزارش‌گیری وظایف کاری و سازمانی، با قابلیت اتصال به سرویس‌های ایمیل سازمانی (Outlook / IMAP)، جیمیل (Gmail API)، جیرا (Jira) و سیستم نوتیفیکیشن موبایل (ntfy).

---

## ویژگی‌ها و ساختار پروژه

- **رابط کاربری مدرن و واکنش‌گرا**: طراحی شده به زبان فارسی (RTL)، تایپوگرافی وزیرمتن، استایل‌های مدرن بر پایه Tailwind CSS و آیکون‌های Lucide.
- **تقویم و دیت‌پیکر شمسی (جلالی)**: محاسبه دقیق تاریخ شمسی و تعیین ضرب‌الاجل (Due Date) برای کارها با ساعت و دقیقه.
- **جداسازی کامل دو محیط توسعه و اجرا**:
  - **محیط اصلی (Main / Production)**: محیط پایدار و نهایی جهت تحویل به مشتری و کاربران اصلی با دیتابیس اختصاصی `data/tasks.db` روی پورت `8000`.
  - **محیط تست (Test / Development)**: محیط آزمایشی و ایزوله جهت دولوپ، آزمایش تغییرات و سناریوهای تستی با دیتابیس جداگانه `data/tasks_test.db` روی پورت `8080`، بدون کوچک‌ترین تداخل با اطلاعات مشتری.
- **سیستم پوش خودکار با قابلیت Retry و خودترمیمی (Self-Healing)**: اسکریپت هوشمند `scripts/auto_push.py` که تغییرات را پس از پاس شدن تست‌ها به مخزن گیت‌هاب پوش کرده و در صورت بروز خطای شبکه یا تداخل، تا ۳ مرتبه تلاش مجدد (با backoff و rebase خودکار) انجام می‌دهد.
- **قوانین یکپارچه هوش مصنوعی (Antigravity Rules)**: تعریف شده در `.agents/rules/git-sync-workflow.md` و `GEMINI.md` تا تمامی تغییرات به صورت اتوماتیک و استاندارد بدون نیاز به دستور دستی کاربر کامیت و پوش شوند.
- **خط لوله CI/CD در گیت‌هاب (GitHub Actions)**: اعتبارسنجی سینتکس، اسکن امنیتی سکرت‌ها و دیتابیس‌ها، اجرای تست‌های خودکار در هر دو محیط و انتشار بسته‌های استقرار Staging و Production.
- **رعایت کامل اصول امنیتی**:
  - جلوگیری قطعی از کامیت فایل‌های دیتابیس (`*.db`) و اطلاعات حساس یا توکن‌ها از طریق `.gitignore`.
  - جلوگیری از آسیب‌پذیری Directory Traversal در سرور وب پایتون.
  - اعمال هدرهای امنیتی مدرن (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`).
  - ایمن‌سازی کوئری‌های دیتابیس با پارامترهای امن SQLite.

## نحوه اجرای برنامه در محیط‌های مختلف

### ۱. اجرای محیط تست (Test Environment)
جهت آزمایش ویژگی‌های جدید بدون دستکاری دیتابیس اصلی:
```bat
run_test.bat
```
یا از طریق خط فرمان:
```bash
set SOVAPP_ENV=test
set PORT=8080
python server.py
```
آدرس مرورگر: `http://localhost:8080/tasks.html`

### ۲. اجرای محیط اصلی و مشتری (Production Environment)
جهت استفاده مشتری و تحویل نهایی:
```bat
run_prod.bat
```
یا از طریق خط فرمان:
```bash
set SOVAPP_ENV=production
set PORT=8000
python server.py
```
آدرس مرورگر: `http://localhost:8000/tasks.html`

### ۳. اجرای سریع و پیش‌فرض
```bat
run.bat
```

## سیستم پوش خودکار (Auto Push & Retry)

برای ارسال تغییرات به گیت‌هاب بدون نیاز به مراحل دستی:
```powershell
.\scripts\auto_push.ps1 "توضیحات کامیت"
```
یا
```bash
python scripts/auto_push.py "توضیحات کامیت"
```

این اسکریپت به صورت خودکار:
1. کدهای پروژه را تست و اعتبارسنجی می‌کند (`py_compile` و `unittest`).
2. امنیت فایل‌ها را بررسی می‌کند تا دیتابیس یا توکنی کامیت نشود.
3. در صورت موفقیت، تغییرات را کامیت و روی شاخه فعال پوش می‌کند.
4. اگر با خطایی مواجه شود، با مکث هوشمند و Rebase اتوماتیک تا ۳ بار Retry می‌کند.

## اجرای تست‌های خودکار

```bash
python -m unittest discover -s tests -v
```

## ساختار شاخه‌ها (Git Branches)

- `main`: شاخه رسمی و آماده برای ارائه به مشتری (Production).
- `develop`: شاخه فعال برای توسعه، تست و افزودن قابلیت‌های جدید.
